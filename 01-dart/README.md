# Módulo 01: Dart

Este módulo cubre las bases fundamentales del lenguaje Dart, desde la configuración del entorno hasta los conceptos clave de sintaxis y estructura.

## Estructura del Módulo

- `00_print.dart`: Ejemplo introductorio del punto de entrada `main()` e impresiones en consola.
- `01_variables.dart`: Guía completa de sintaxis que abarca:
  - Tipos de datos primitivos (`int`, `double`, `String`, `bool`) e inferencia (`var`).
  - Inmutabilidad (`final` y `const`) y manejo de nulos (*Null Safety*).
  - Colecciones (`List`, `Set`, `Map`).
  - Control de flujo (`if`, `else if`, `else`, `switch`).
  - Enumerados (`enum`).
  - Funciones sencillas y *Arrow Functions*.
  - Programación Orientada a Objetos (clases, constructores y métodos).
